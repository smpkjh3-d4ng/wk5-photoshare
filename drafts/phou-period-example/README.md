# 모임 기간 / 사진 불러올 기간 분리 예시

기존 수정 시안을 복사한 독립 예시입니다. 기존 시안과 공개 배포본은 변경하지 않았습니다. 브라우저 저장 키도 분리했습니다.

- 앨범 만들기와 앨범 정보 수정에는 모임 기간을 표시합니다. 앨범 상단도 모임 기간을 표시합니다.
- 사진 추가에는 사진을 불러올 기간을 표시하고 모임 기간을 기본으로 가져옵니다.
- 기간 변경은 이번 추가 작업에만 적용합니다. 앨범의 모임 기간은 변경하지 않습니다.
- 다음에 사진을 추가할 때는 다시 모임 기간을 기본값으로 사용합니다.

검증 예: 모임 기간 2026.10.25~29 / 이번 사진 추가 2026.10.25~26. 추가 후와 새로고침 후에도 모임 기간은 25~29로 유지됩니다. 8개 흐름 검증과 JavaScript 오류 0건을 확인했습니다. 사진 불러오기·업로드는 기존 프로토타입 시연 방식입니다.

verification 폴더에 두 화면 캡처, 실제 검증 결과와 재실행 스크립트를 보관했습니다.
