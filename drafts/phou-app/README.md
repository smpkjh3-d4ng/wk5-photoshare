## 열기

`index.html`은 CSS와 JavaScript가 포함된 단일 HTML입니다. 내려받아 일반 브라우저에서 열거나 기존 로컬 서버에서 `/drafts/phou-app/`을 엽니다. 이 클라우드의 관리형 Chromium은 `file://` 탐색을 차단하므로, 자동 검증은 HTTP로 제공한 동일 파일에서 진행했습니다.

## 반영한 내용

- 홈 하단 메뉴 제거. 기존 우측 상단 프로필 버튼을 통해 메뉴로 이동합니다.
- 사진을 불러올 기간: 시작은 지금부터, 종료일은 없음/설정 선택. 생성·기간 변경·앨범 정보 수정에 같은 구조를 사용합니다.
- 전체/베스트컷 2개 탭. 전체 탭에 검색·업로더·내 사진·사람·장소·시간·음식·풍경 필터를 통합했습니다. 필터는 항상 보이는 한 줄 가로 스크롤이며, 올린 사람은 드롭다운 대신 사람별 선택 목록으로 표시합니다.
- 검색은 현재 프로토타입의 사진 번호와 업로더 메타데이터를 대상으로 합니다. AI 사진 내용 검색은 연결하지 않았습니다.
- 하단 다운로드/+ 배치 유지. 베스트컷 다운로드 명칭과 실제 저장 대상 장수를 표시합니다. 내 업로드를 제외하며, 묶음은 대표 사진 저장을 기본으로 합니다. 기존과 같이 실제 파일 저장 대신 저장 요청을 시연합니다.
- 앨범 참여자 옆 친구 + 버튼에서 기존 친구 선택·초대 화면으로 바로 이동합니다. QR·링크 공유 버튼과 구분합니다. 실제 초대 알림은 전송하지 않습니다.
- 사진별 댓글: 목록, 입력, 등록, 댓글 수, 빈 입력 방지, 닫기, 브라우저 로컬 저장. 다른 앨범·사진의 댓글과 분리합니다. 댓글은 같은 브라우저에서만 유지되며 서버 공유가 아닙니다.
- 좋아요 수 표시와 사진만 보기 동작을 유지했습니다.
- 원본 삭제 질문·설정과 용량 안내·용량 메뉴를 제거했습니다.
- 기존 시각 디자인과 사진 자리표시자를 유지했습니다. 더미 사진은 추가하지 않았습니다.

## 검증

`verification/results.json`에 실제 실행 결과를 기록했습니다. 모바일 크기와 데스크톱 Chromium에서 버튼을 클릭해 생성, 탐색, 초대, 업로드, 댓글 저장·재접속 등을 확인했습니다. 이 환경에서 직접 파일 URL 열기는 브라우저 관리 정책으로 검증하지 못했습니다. 실제 휴대폰의 네이티브 키보드 동작은 별도 기기 확인이 필요합니다.

- 시작·종료를 한 박스 안의 두 행으로 정리했습니다. 지금부터 시작/종료일 없음 기본값과 날짜 선택 기능을 유지합니다. 종료 행을 눌러 종료일 없음 또는 설정을 고를 수 있습니다.

- 16개 기존 검증과 친구 + 진입, QR/공유 순서, 유효기간 편집 버튼을 확인했습니다.

## 앨범 필터 간소화

앨범 검색창과 내가 나온 사진/내가 올린 사진만 단독 필터를 제거했습니다. 남은 필터는 전체, 사람, 장소, 시간, 음식 · 풍경, 올린 사람입니다. 올린 사람 안에서 나를 선택하는 기능은 유지합니다. 홈 앨범 검색은 유지합니다.

## 업로더·다운로드 보완

올린 사람 목록은 전체/나/참여자 1/참여자 2/참여자 3입니다. 기존 자리표시자 사진의 시연용 업로더 메타데이터를 구분하며 새로운 사진은 추가하지 않았습니다. 각 선택의 다운로드 버튼이 작동합니다. 내 사진만 표시된 경우에는 내 사진을 저장할 수 있도록 했으며, 다른 사람 사진이 포함된 범위에서는 기존 내 사진 제외 기본 동작을 유지합니다. 실제 파일 저장은 기존처럼 시연입니다.

## 저장 옵션 체크박스

대표 사진만/모든 사진 저장 선택 아래, 최종 저장 버튼 위에 내가 올린 사진은 빼고 저장해요 체크박스를 추가했습니다. 체크와 라디오 선택에 따라 두 옵션 및 확인 버튼의 장수가 즉시 바뀌고 실제 시연 저장 대상도 함께 변경됩니다. 내 사진만 보는 경우 초기 체크는 꺼져 있으며 사용자가 켜서 대상이 0장이 되면 저장 버튼을 비활성화합니다.

## 좋아요 필터·초대 기간·용어 통일

좋아요한 사진 필터는 현재 사용자의 좋아요를 기준으로 표시하며 취소하면 목록에서 빠집니다. 신규/재발급 초대 기본 기간은 3일이고 QR 화면에 링크는 3일 동안 유효해요.를 표시합니다. 이전 기본 링크도 만료를 연장하지 않는 범위에서 3일 이내로 맞춥니다. 사용자가 유효기간을 별도 변경하면 안내도 그 기간을 반영합니다. 설정의 사진 수집은 사진 불러오기로, 영상 제외는 동영상 제외로, 대표사진/1장만은 대표 사진만으로 통일했습니다.
